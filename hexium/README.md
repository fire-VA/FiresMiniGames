# FiresMiniGames

**Updated for Valheim 1.0.**

Part of the Fires mod family for Valheim.

## Licence

FiresMiniGames is licensed under the **GNU General Public License, version 3 (GPL-3.0)**; the full text is in
`LICENSE`. It is GPL because it contains GPL components (the DOOM and Game Boy Advance cores below). The source
code is available at https://github.com/fire-VA/FiresMiniGames.

**No game data is included.** The DOOM machine needs a WAD file that you place in its folder yourself: the free
`freedoom1.wad` from https://freedoom.github.io/ or your own `doom1.wad`. id Software's commercial `doom.wad` is
not distributed with this mod.

## Third-party components
